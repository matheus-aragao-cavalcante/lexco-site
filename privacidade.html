Política de Privacidade

Última atualização: 4 de novembro de 2026

Esta política explica como o Lexco, sistema de gestão jurídica para computador, trata as informações dos seus usuários.

1. Armazenamento local

Todos os dados cadastrados no Lexco (usuários, processos, prazos, eventos, partes, anexos e histórico) são armazenados somente no computador onde o programa está instalado. O Lexco não possui servidores e não envia esses dados ao desenvolvedor nem a terceiros.

2. Integração com o Google (opcional)

O usuário pode, por iniciativa própria, conectar uma conta Google para salvar e restaurar backups no seu Google Drive. Ao conectar, o Lexco solicita apenas as permissões:

  • Google Drive — arquivos criados pelo app (https://www.googleapis.com/auth/drive.file): usada para criar, listar, baixar e excluir os arquivos de backup gerados pelo próprio Lexco. O Lexco não tem acesso a nenhum outro arquivo do seu Drive.
  • Endereço de e-mail, nome e foto do perfil (openid, email, profile): usados para entrar no Lexco com a conta Google, criar o seu usuário local (nome e foto) e mostrar qual conta está conectada. Ficam guardados apenas no seu computador.

Os backups são enviados diretamente do seu computador para o seu Google Drive, sem passar por servidores do desenvolvedor. As credenciais de acesso concedidas pelo Google ficam guardadas apenas no seu computador.

3. Uso limitado dos dados do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Os dados obtidos do Google não são vendidos, compartilhados, usados para publicidade nem para treinar modelos de inteligência artificial.

4. Compartilhamento

O Lexco não compartilha dados pessoais com terceiros.

5. Seus controles

  • Desconectar a conta Google a qualquer momento pelo próprio Lexco;
  • Revogar o acesso em myaccount.google.com/permissions;
  • Excluir os backups diretamente no seu Google Drive;
  • Apagar todos os dados locais desinstalando o programa e removendo a pasta de dados do Lexco.

6. Segurança

Como os dados ficam no seu computador e no seu Google Drive, recomendamos proteger o dispositivo com senha e manter a conta Google com verificação em duas etapas.

7. Alterações

Esta política pode ser atualizada; a data no topo indica a versão vigente.
